## Conventions
- File names are lowercase, hyphenated.
- CSS classes use the `pp-` prefix to avoid collisions.
- Plant SVG is generated by one `plantSVG(stage, wilted)` function — never duplicate SVG markup across the file.
- The `.kiro/` directory is part of the submission. Never add it to `.gitignore`.
